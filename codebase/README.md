# Module starlasu-codebase

Represents a codebase: a named collection of files, each with its code, AST, tokens and parsing issues.

# Package com.strumenta.starlasu.codebase

`Codebase` and `CodebaseFile`; `FileBasedCodebase`, which parses the files with the given extensions found under a
directory; and functions to serialize codebase files to and from LionWeb nodes.
