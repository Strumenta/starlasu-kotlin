# Module starlasu-lionweb-client

Stores and retrieves Starlasu ASTs in a [LionWeb](https://lionweb.io) repository.

# Package com.strumenta.starlasu.lionwebclient

`StarlasuClient` wraps the LionWeb Kotlin client: it converts ASTs to LionWeb nodes (and back) with a
`LionWebModelConverter`, and manages partitions and the attachment of ASTs to them.
